- https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2024.1362658/full
    - largely clune and stanley co-evolution in more sophisticated terms
    - more emphasis on self-construction as the starting point of the frame problem
    - three components, the lowest is self construction, the middle is adaptation to feedback, the highest is niche construction, and they interact and co-sustain each other, but how exactly is not known
    - increasing complexity in terms of adaptive behaviour, cognition and meta-cognition is said to inevitably follow from the above three-part interaction and clune-stanley-style local search. no formal argument though.
    - this is largely the difference between autopoiesis and homeostasis
    - they tie this to finitude: not only autocatalysing existence, but maximising the runway to death is what their version of autopoiesis does, which also ties into urgency
    - argues that formalising the right problem runs into halting problem-type recursions, thus is incomputable in general, as you run into trying to formalise formalisation itself
    - they say that agency is being able to maintain organisational closure
    - they say this is non-algorithmic, but this seems like a restricted definition of what an algorithm is. it does not have a closed-form objective that it maximises, for sure

- econ choice discretisation literature, Sims the Elder about discrete action spaces with a similar argumentation, potentially useful experiments: [https://home.cerge-ei.cz/matejka/discrete_actions.pdf](https://home.cerge-ei.cz/matejka/discrete_actions.pdf)
    - This is about the other side of the coin, i.e. the channel from the (estimated) state to the action, instead of the channel from the observation to the state
        - So in this case the channel capacity is dictating how many bits can the agent process from the state signal when choosing an action, that is, how many states can it actually differentiate -> discrete number of optimal actions
        - This constraint is ultimately a computational one, with lambda (which is internal, thus difficult to measure) standing in for N
        - Then our assertion is that you don’t even need an action for the first channel to exist at all, and it definitely exists (somewhat) invariantly across many different action channels, and its capacity is determined by the task/environment instead of agent architecture
        - There actually must be a computational constraint that has the same effect as an observational one: say the agent can only compute posteriors up to some bits of precision. This is fully equivalent to not even being able to observe those bits. But now the constraint is internal and hard to measure.
        - Is there a similar equivalence in the reverse direction? Limits in terms of computation time are similar but not fully: cutting trials short imposes a bit limit, but an unknown one, as we don’t know the time required for one computational step. So the external constraint would have to be something like a caloric one, limiting entropy changes in the computational substrate. I don’t know if such a thing exists.
            - Or it’s a meta-cognitive observation that’s equivalent to a computation this way
    - This reference supposedly shows in data that the amount of information determines the discretisation in corporate price-setting: [https://econweb.umd.edu/~stevens/papers/Stevens%20Coarse%20Pricing%20Policies.pdf](https://econweb.umd.edu/~stevens/papers/Stevens%20Coarse%20Pricing%20Policies.pdf)
        - I guess the choice of these companies to acquire more or less data reflects how available observations are to them.
        - So this isn’t necessarily inattention in the sense of a computational limitation, but a constraint that could be similar to ours, but I’d be surprised if the paper was conclusive about this
