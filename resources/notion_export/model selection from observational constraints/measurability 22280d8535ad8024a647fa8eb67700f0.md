Prior parametrisation ideas:

- Walsh basis, where the inverse of the DC coefficient is the discretisation measure
    - We would have to integrate over a larger number of coefficients, hard to see how data-intensive this would be
    - bases are non-local, this could make things harder
- Haar wavelets
    - they are negative as well as positive, so something like the scaling function would have to be used
    - again, even more parameters to integrate out
- Number of spikes to suppress a slab
    - fixed-width spikes, you can add as many of them as you want
    - this will end up being a ton of parameters as well
    - the interesting thing is not really the number of spikes, but the degree to which one can suppress the slab by adding them
        - but if you can add however many, you can always completely suppress the slab

We will have to assume:

- a particular model structure, including latent variable semantics
    - if we want to keep things implicit, the question comes up how natural is a particular choice. e.g. is a correlation parameter something that people would naturally look for?
    - albeit this can be relaxed somewhat: **we can assume a more generic latent structure** (e.g. a bunch of first- and second-order sufficient stats), and the MI objective will actually boil them down to the ones that are estimable, given the choice of likelihood
    - what we DON’T assume: that the subject chose the prior in a certain way. this is what we’re trying to test
- a likelihood function, together with any parametrisation it may require
- that the subject conducted Bayesian updates in the model throughout the session, and now has the posterior as the prior
    - what happens if there is no learning? can we induce such a scenario that the perceptual model is set up, together with some prior, preferably urgency-based, but then no learning appears, but the prior remains measurable?
- how the test task boils down to probabilistic computations, e.g. if a familiarity judgement is made as the more probable of the two stimuli under the predictive distribution using the assumed model and the learned prior
- how the choice is made after the probabilistic computation is done: what sort of decision noise parameters are there?
- a parametrisation for the prior: a basis set, where the coefficients get (at least) point-estimated
    - albeit we will often want to integrate over some coefficients to address a particular question
    - ideally we always want to boil down the estimation process to one quantity, compared across two conditions

- Completely stripped down example:
    - coin flip
    - hypothesis space: trident vs. uniform
        - we can even assume that this is after learning
            - after infinitely many observations everything is a delta, just possibly at different locations
                - is this an opportunity for testing? no - this is directly contradictory to the urgency setup, the agent has to assume few observations, and this has to remain somewhat plausible at least - so far from infinity
            - so a fixed number of observations has to be assumed (this is N anyway)
                - but if N is low, then people can’t be expected to be anywhere near a reasonable estimate of what the latent might be
                    - so this is similar to having almost no learning
                    - but then the test trials’ bias will be quite significant compared to the training set
                    - **can we have a setting where the training is fairly long in total, but always resets such that the urgency remains high, thus it never makes sense to de-discretise?**
                        - tiger detection is kinda like that
                        - low information tasks in general are better in the sense that the training can be temporally longer while still expecting strong discretisation
                        - but the informationally speaking, it might be easier to overwrite observations still
                        - for this, one will definitely need some normative theory of applying the representational step in a sequence
                    - **and then this is more of a meta-learning question - did the subject learn that this is best handled as a discrete problem regardless of the context-specific statistics, or not?**
                        - because in the test trials, just having the foils e.g. 30 times after a 5-trial training or something will influence this
                - and if N is high, then the prior will be quite indistinguishable from a continuous one
            - of course the trident becomes a bident then, and the uniform a bumpier Beta
    - direct evaluation of the posterior at certain observations makes the comparison trivial - if it’s nonzero anywhere interesting, then we have a winner
        - so it’s better to have e.g. a noiseless report of the probability of the stimulus under the model - this is probably the most direct non-trivial measure.
        - but it’s possible that we will have to allow for some noise in this report as well, otherwise it becomes almost always contradictory to some or all hypotheses
        - e.g. some Gaussian motor noise on the reporting equipment
    - how does the experimenter-posterior probability of one hypothesis over the other evolves as a function of the number of test trials, the motor noise, and the number of training trials
